# Auth — идентичность и сессии

Сервис аутентификации: анонимный вход по device-id, выпуск и обновление токенов
(access/refresh), учёт сессий и устройств. Единственный источник истины о
пользователе как таковом (User); профиль создаётся асинхронно в
[../../profile/](../../profile/CONTEXT/purpose.md) по событию Kafka.
