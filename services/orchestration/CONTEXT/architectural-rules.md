# Architectural rules

- Новый внутренний маршрут = правка `proxy/routes/*.routes.ts` + контроллер +
  gRPC-клиент целевого сервиса; сам `ProxyRequest` (метод/путь/заголовки/тело) при этом
  не меняется.
- Маршруты с `authRequired=false` (signIn/refresh/verify) — единственное место, где
  снимается требование JWT; расширение — осознанное решение.
- Redis-кеш не является источником истины; инвалидация — через TTL/пересоздание.
